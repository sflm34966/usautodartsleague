US AutoDarts League Unified App v0.7.10
======================================

ONE APK FOR PLAYER, MODERATOR, AND MANAGER

Server Manager v0.6.5 alignment:
- Neutral Player 1 / Player 2 matches. No Home/Away roles or Home/Away legs.
- Regular-season and playoff matches are generated by the server.
- Managers cannot create matches. They can edit/reschedule existing generated matches, correct results, approve, and void where the server permits.
- Moderators cannot create matches. They can reschedule generated matches and enter results.
- Manager-only Season Setup supports create/edit/delete, schedule generation/regeneration, and playoff checks.
- Player Matches and Standings include season selection.
- Manager scheduling is entered in Eastern Time; player match displays use the local label returned by the server for that player's saved time zone.

RULES
- Settings > League Rules reads /api/rules from the league server.
- The last successful rulebook is cached only as an offline fallback.
- Bundled offline fallback now matches the authoritative 30-rule v1.0 Draft.
- Future rule changes on the server appear without rebuilding the APK.

TROPHIES / BADGES
- Earned awards read from /api/awards.
- Current bundled artwork stays as the visual fallback because it already matches the approved design.
- The app is forward-compatible with /api/award-catalog and server-hosted image_url artwork, so future awards can be added without rebuilding once the server endpoint is added.
- Active fallback catalog contains 25 awards. Relegation Avoided and Multiple Division Winner are removed.
- Win Streak means 5 consecutive league match wins.
- Existing award-count badge appearance and placement are unchanged.

NAVIGATION
- In app submenus, swipe right to go back.
- After going back, swipe left to go forward to the screen you just left.
- Manager and Moderator internal server menus use the same swipe-history behavior.

DROPDOWNS
- Fixed-choice values use dropdowns where the server's valid values are known.
- Free text remains for genuinely free-form values such as names, email, passwords, season names, and dates.

BUILD
Double-click BUILD_APK_WINDOWS.bat on the Windows build PC.
EAS cloud build produces the APK.
Android package remains com.usautodarts.league so this upgrades the existing app.
