US AutoDarts League App v0.7.29 - Normal Build Workflow

1. Upload/replace this project in the existing GitHub repository as usual.
2. Open Codemagic.
3. Start the existing "US AutoDarts League Android APK" workflow manually.
4. When the build succeeds, download the release APK from Codemagic artifacts.
5. Publish/replace the APK through the same GitHub release process you were already using.

No GitHub token, automatic tag workflow, or automatic release publishing is required for this package.

v0.7.29 app change:
- Players can add evidence images repeatedly before uploading.
- A local evidence tray lets them review/remove/clear selections.
- Upload All sends the queued images in batches of up to 10.
- Works for regular league matches and manager-created tournament matches.
- Server v0.9.69 remains authoritative for OCR, caching, rejection, and combining evidence.
